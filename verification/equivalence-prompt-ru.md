# Задача: проверить, что формулировка на Lean 4 говорит ровно то же, что математическая теорема

Вы проверяете формализацию. Ваша единственная задача — решить, **эквивалентна ли логически формулировка
на Lean** (ниже) **математической теореме** (ниже). **Не** пытайтесь доказать или опровергнуть теорему и не
оценивайте доказательство: доказательство на Lean проверено машиной (нет `sorry`, только стандартные аксиомы
`propext`, `Classical.choice`, `Quot.sound`). Остаётся единственный риск — что формальное утверждение означает не
то, что математическое. Будьте скептичны и точны.

## 1. Математическая теорема

Пусть `n ≥ 2` и `P = [0,p₁]×…×[0,pₙ]`, `pᵢ ≥ 0` (замкнутая коробка в евклидовом `n`-мерном пространстве). При
`A, B ≥ 0` *прямоугольник* `A × B` — это `{x₀ + s·A·u + r·B·v : s, r ∈ [0, 1]}` для некоторой точки `x₀` и
ортонормированной пары `u, v ∈ ℝⁿ`; он *помещается* в `P`, если `x₀, u, v` можно выбрать так, чтобы он лежал в
`P` (равносильно: некоторая изометрия `ℝⁿ`, включая отражения, переводит прямоугольник
`[0,A]×[0,B]×{0}×…×{0}` внутрь `P`). Для `S ⊆ {1,…,n}` пусть `‖p_S‖² = Σ_{i∈S} pᵢ²`, `x₊ = max(x, 0)`.

**Критерий Карвера** (плоскость). Пусть `X ≥ Y ≥ 0` — стороны плоского прямоугольника, `a ≥ b ≥ 0` — стороны
другого. Прямоугольник `a × b` помещается в прямоугольник `X × Y` тогда и только тогда, когда
(i) `a ≤ X` и `b ≤ Y`, или
(ii) `a > X`, `b ≤ Y` и `((X+Y)/(a+b))² + ((X−Y)/(a−b))² ≥ 2`.
`Carver(a, b; X, Y)` — это условие после сортировки обеих пар по убыванию.

**Теорема.** Пусть `n ≥ 2`, `pᵢ ≥ 0`, `A, B ≥ 0`. Прямоугольник `A × B` помещается в `P` тогда и только тогда,
когда существуют индексы `k ≠ l` и разбиение `S ⊔ T = {1,…,n} ∖ {k, l}`, для которых
`Carver(a′, b′; p_k, p_l)`, где `a′ = √(A² − ‖p_S‖²)₊`, `b′ = √(B² − ‖p_T‖²)₊`.

## 2. Формулировка на Lean 4 (код дословно, комментарии сокращены; Lean 4 + Mathlib, индексы `0, …, n−1`)

```lean
namespace RectInNBox

variable {n m : ℕ}

/-- Euclidean space `ℝⁿ`. -/
abbrev En (n : ℕ) := EuclideanSpace ℝ (Fin n)

/-- The closed box `∏ᵢ [0, qᵢ]` in `ℝⁿ` with edges along the coordinate axes. -/
def boxN (q : Fin n → ℝ) : Set (En n) := {x | ∀ i, 0 ≤ x i ∧ x i ≤ q i}

/-- The vector of edges `q : Fin m → ℝ` extended by zeros to `Fin n` (`m ≤ n`). -/
noncomputable def pad (h : m ≤ n) (q : Fin m → ℝ) : Fin n → ℝ :=
  Function.extend (Fin.castLE h) q 0

/-- The box with edges `q` fits into the box with edges `p`. -/
def FitsN (p q : Fin n → ℝ) : Prop := ∃ f : En n ≃ᵢ En n, f '' boxN q ⊆ boxN p

/-- Carver's criterion for sorted sides (`X ≥ Y` — the box, `a ≥ b` — the rectangle). -/
def CarverS (a b X Y : ℝ) : Prop :=
  (a ≤ X ∧ b ≤ Y) ∨
    (X < a ∧ b ≤ Y ∧ 2 ≤ ((X + Y) / (a + b)) ^ 2 + ((X - Y) / (a - b)) ^ 2)

/-- Carver's criterion after sorting both pairs in decreasing order. -/
def Carver (a b X Y : ℝ) : Prop := CarverS (max a b) (min a b) (max X Y) (min X Y)

open Finset Real in
theorem fitsN_rect_iff_explicit (h : 2 ≤ n) (p : Fin n → ℝ) (hp : ∀ i, 0 ≤ p i) {A B : ℝ}
    (hA : 0 ≤ A) (hB : 0 ≤ B) :
    FitsN p (pad h ![A, B]) ↔
      ∃ k l : Fin n, k ≠ l ∧ ∃ S T : Finset (Fin n), Disjoint S T ∧ S ∪ T = univ \ {k, l} ∧
        Carver (√(A ^ 2 - ∑ i ∈ S, p i ^ 2)) (√(B ^ 2 - ∑ i ∈ T, p i ^ 2)) (p k) (p l)
```

Справка по обозначениям Lean/Mathlib:
* `EuclideanSpace ℝ (Fin n)` — `ℝⁿ` с евклидовым расстоянием; `x i` — `i`-я координата.
* `En n ≃ᵢ En n` — тип изометрических биекций `ℝⁿ` на себя (`IsometryEquiv`).
* `f '' S` — образ множества `S` при `f`; `⊆` — включение множеств.
* `![A, B] : Fin 2 → ℝ` — вектор `(A, B)`. `Fin.castLE h : Fin m → Fin n` — вложение `i ↦ i`;
  `Function.extend g q 0` равна `q j` в точке `g j` и `0` вне образа `g`.
* `Finset (Fin n)` — конечное множество индексов, `univ` — все индексы, `Disjoint S T` означает `S ∩ T = ∅`,
  `∑ i ∈ S, f i` — конечная сумма.
* `√t` — это `Real.sqrt t`, определён для всех вещественных и равен `0` при `t < 0`.
* Деление на ноль в Lean определено: `x / 0 = 0`.

## 3. Что проверить (ответьте на каждый пункт)

1. Совпадает ли `boxN q` с `[0,q₀]×…×[0,q_{n−1}]` (замкнутая, вдоль осей, одна вершина в начале координат)?
2. Совпадает ли `FitsN p q` с «коробка `q` помещается в коробку `p`» (любая изометрия, отражения разрешены)?
   То же ли самое — квантор по изометрическим **биекциям** и по всем изометриям `ℝⁿ`?
3. Является ли `boxN (pad h ![A, B])` в точности прямоугольником `[0,A]×[0,B]×{0}×…×{0}`, так что
   `FitsN p (pad h ![A, B])` означает «прямоугольник `A × B` помещается в `P`»?
4. Совпадают ли `CarverS` / `Carver` с критерием Карвера из §1, включая сортировку, и может ли соглашение
   `x / 0 = 0` изменить ответ в ветке (ii)?
5. Совпадает ли правая часть с условием теоремы: разбиение (`Disjoint S T ∧ S ∪ T = univ \ {k, l}`), срезка
   `(·)₊` (через `√t = 0` при `t < 0`), порядок аргументов `Carver`?
6. Соответствуют ли гипотезы `h`, `hp`, `hA`, `hB` условиям `n ≥ 2`, `pᵢ ≥ 0`, `A, B ≥ 0` — без лишних и без
   недостающих, и не делают ли они утверждение пустым?
7. Есть ли ещё какой-то способ, которым формулировка на Lean слабее, сильнее или пуста по сравнению с
   математической теоремой (неявное приведение типов, сдвиг индекса на единицу, определение, которое тривиально
   истинно или ложно)?
